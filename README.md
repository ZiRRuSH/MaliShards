# MaliShards

A simple Soul Shard manager for WoW: Forever by Mali Gnosis.

Set how many Soul Shards to keep, then use the included macro or add
`/mshards delete` to another out-of-combat macro. Each press deletes one
excess shard until you reach your limit.

Click the minimap icon for settings, or type `/mshards help` for commands.
Changing icon visibility with `/mshards minimap` requires `/reload`.

Created because none of the similar addons I tried worked in WoW: Forever.
